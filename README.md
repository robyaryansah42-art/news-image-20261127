# The World Today — Friday 27 November 2026

A one-page newspaper front page summing up the world news of
**Friday 27 November 2026**, drawn entirely by code. Entry for the
make.fun competition `news-image-20261127`.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024×1024, under 20 KB). The program uses
only the Python 3 standard library — no network, no external files, no
clock, no randomness — so two runs produce byte-identical output.
